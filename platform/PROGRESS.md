# Axiom Siam — สรุปงานที่ทำแล้ว

อัปเดต: 14 ก.ค. 2569

---

## ภาพรวม

แพลตฟอร์ม OEM/ODM ชุดกีฬาครบวงจร — ลูกค้าออกแบบเสื้อเองบนเว็บ ใส่ชื่อ-เบอร์ทั้งทีม เห็นราคาทันที สั่งผลิต จ่ายเงิน และตามสถานะได้ในที่เดียว พร้อมตลาดซื้อ-ขายลายจากดีไซเนอร์ และหลังบ้านสำหรับแอดมิน

**โครงสร้าง** — monorepo (npm workspaces)

| ส่วน | เทคโนโลยี | พอร์ต |
|---|---|---|
| `apps/web` | Next.js 14 (App Router) | 3000 |
| `apps/api` | NestJS 10 (prefix `/api/v1`) | 4000 |
| `packages/db` | Prisma + PostgreSQL | 5432 (Docker) |

**ขนาดงาน** — 33 ตารางใน DB · 12 โมดูล API · 18 หน้าเว็บ · 16 ไฟล์เทสต์

## 1. ระบบสมาชิก + ความปลอดภัย

- **สมัคร/เข้าสู่ระบบด้วยอีเมล + รหัสผ่าน** พร้อมยืนยันอีเมล, ลืมรหัสผ่าน, รีเซ็ตรหัสผ่าน
- **เข้าสู่ระบบด้วย Google** (Google Identity Services) — เซิร์ฟเวอร์ตรวจ ID token กับ Google เอง (เช็ก `aud` + `email_verified`) สมัครอัตโนมัติครั้งแรกโดยไม่ต้องมีรหัสผ่าน
- **อีเมลจริงผ่าน Resend** — ยืนยันอีเมล (24 ชม.) / รีเซ็ตรหัสผ่าน (1 ชม.) ดีไซน์แบรนด์ Axiom ถ้าไม่ใส่ API key จะ log ลง console แทน (ไม่พังระบบ)
- **จัดการรหัสผ่าน** — บัญชี Google ล้วนตั้งรหัสผ่านครั้งแรกได้โดยไม่ต้องกรอกรหัสเดิม, บัญชีที่มีรหัสผ่านแล้วต้องยืนยันรหัสเดิม
- **2FA (TOTP)** สำหรับแอดมิน — เปิด/ปิด/ยืนยัน รองรับบัญชีที่ไม่มีรหัสผ่าน
- **Rate limiting** เขียนเอง ไม่พึ่ง dependency (สมัคร 5 ครั้ง/ชม./IP, Google 20/5 นาที)
- **Audit trail** — บันทึกทุกการกระทำของแอดมิน พร้อมหน้าดูย้อนหลัง

## 2. โปรแกรมออกแบบเสื้อ (`/design`)

- Editor แบบ Illustrator — vector, เลเยอร์, ตัวหนังสือโค้ง 28 ฟอนต์, คีย์ลัด, copy/paste
- ขลิบ 4 ระดับ (ไม่มี / คอ / คอ+แขน / เต็ม), โหมดแนวตั้ง-แนวนอน, ทิศทาง export ตามหน้าผ้า
- โหมดพรีวิว 3D บนตัวเสื้อ
- **Roster** — วางรายชื่อทั้งทีมจาก Excel ทีเดียว แล้ว generate ทุกตัว export เป็น ZIP
- เซฟดีไซน์เข้าบัญชี → ขอใบเสนอราคา → สั่งผลิตต่อได้เลย

## 3. ตลาดลาย (Marketplace)

- ดีไซเนอร์ลงขายลาย, หมวดหมู่, ลายแนะนำ (featured), หน้าโปรไฟล์ดีไซเนอร์
- ระบบซื้อลาย + ส่วนแบ่งค่าคอมมิชชัน + จ่ายเงินดีไซเนอร์ (payout)
- รายงานลายผิดลิขสิทธิ์ + **ตรวจจับรูปซ้ำอัตโนมัติ** ตอนลงขาย

## 4. คำสั่งซื้อ + การเงิน

- เครื่องคิดราคาขั้นบันไดอัตโนมัติ (ตามจำนวน/ผ้า/ขลิบ)
- **ชำระเงินด้วยการโอน + แนบสลิป** (ไม่ใช้ Stripe แล้ว) — PromptPay QR ที่ใส่ยอดมาให้พร้อม + เลขบัญชีบริษัท ลูกค้าอัปโหลดสลิป แอดมินกดอนุมัติ
- กันสลิปซ้ำ 2 ชั้น: sha256 ของรูป + เลขอ้างอิงธนาคาร (unique ใน DB) — สลิปเดียวจ่ายได้ออเดอร์เดียวเท่านั้น
- ใบแจ้งหนี้ออกอัตโนมัติเมื่ออนุมัติสลิป (พิมพ์ได้)
- ติดตามสถานะการผลิต + เลขพัสดุ + ประวัติสถานะ + คืนเงิน
- แจ้งเตือนในเว็บ + อีเมล

## 5. หลังบ้านแอดมิน (`/admin`)

- Dashboard สถิติ, จัดการผู้ใช้ (+ หน้ารายคน), ลาย, รายงาน, payout, ใบเสนอราคา, คำสั่งซื้อ
- ตั้งค่าราคา/คอมมิชชันจาก DB (แก้ได้โดยไม่ต้อง deploy)
- แคตตาล็อก: ผ้า / ไซซ์ / สี
- **Analytics** — funnel, รายได้รายเดือน, cohort + export CSV

## 6. หน้าเว็บ + งาน 3D

- Landing หลัก (`/`) — ธีมขาว-น้ำเงิน, สลับ light/dark, ฉาก 3D, ทีมงาน, ผลงานจริง
- **`/showcase`** — landing แบบ cinematic เลื่อนแล้วเล่า (แรงบันดาลใจจากคลิปอ้างอิง): ฉาก wireframe บินทะลุ, ข้อความโผล่ทีละคำ, ไล่มืด→สว่าง
- **โมเดล 3D ปั้นเองใน Blender** (ต่อผ่าน Blender MCP) — เสื้อกล้าม racerback ผ้าตาข่ายสีดำ โลโก้ AXIOM เงิน → `tank.glb` หมุนได้จริงบนหน้า hero
- SEO, favicon, meta, responsive ครบ

## ยังค้างอยู่

| เรื่อง | สถานะ |
|---|---|
| **ใส่เลขบัญชีจริง** | `/admin` → ตั้งค่า → บัญชีรับเงิน (ยังว่างอยู่ = ลูกค้ายังจ่ายไม่ได้) |
| **Push ขึ้น GitHub** | ติดที่ `.git\index.lock` ค้างในเครื่อง + ต้องใช้ PAT |
| **ลบไฟล์ขยะ** | `_vframes/` และ `_logo_view.png` ที่ root |
| **Google OAuth** | consent screen ยังเป็น Testing — ต้องเพิ่ม test user หรือ publish |
| **สลิปเปิดดูได้โดยไม่ต้องล็อกอิน** | ลิงก์เดารหัสไม่ได้ (มี uuid) แต่ใครมีลิงก์ก็เปิดดูได้ — ควรใส่ guard ก่อนขึ้นจริง |

## เริ่มงานแต่ละครั้ง

```powershell
cd C:\Axiom-siam-website\platform
.\scripts\dev-setup.ps1    # เปิด Docker Desktop ก่อน — สคริปต์เช็ก/สตาร์ท DB + migrate + seed ให้
npm run dev                # เปิด web (3000) + api (4000) พร้อมกัน
```
